# DentLux — Жоба шолуы (Project Overview)

**Жоба атауы:** DentLux — Стоматологиялық клиниканың веб-сайты мен онлайн жазылу жүйесі  
**Репозиторий:** github.com/[org]/dentlux  
**Статус:** Белсенді әзірлеу (Active Development)  
**Басталу күні:** 2026-09-23

---

## Жоба мақсаты

Жеке стоматологиялық клиника үшін пациенттер онлайн жаза алатын, дәрігерлер кестесін басқара алатын веб-жүйе мен Telegram-бот жасау.

1. Онлайн жазылу модулі (веб)
2. Telegram-бот жазылу
