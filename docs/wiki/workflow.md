## 1. Тақта мен карточкалардың мақсаты

GitHub жобасы репозиторийдің **Projects** қойындысына байланыстырылған. «Барлық тапсырмалар» көрінісі жобаның жалпы жұмысын, ал «9-ЗЖ — есеп тапсырмалары» көрінісі есепті дайындауға арналған [№13–18 Issues](https://github.com/akaashia/dentlux-portal/issues?q=is%3Aissue%20%229-%D0%97%D0%96%22) карточкаларын көрсетеді. №13–18 тапсырмаларының атауы, сипаттамасы, чек-листі және аяқталу шарты қазақша жазылған.

`cards_template.csv` ішіндегі **C1–C6** — әзірлеу карточкалары. Олар есеп тапсырмаларымен бірдей емес. Метрикаларға C1–C6 карточкаларының нақты ауысу тарихы енгізіледі; №13–18 тапсырмаларының күндері олардың орнына қолданылмайды. Бастапқы есепте Jira көрсетілгендіктен, трекерді GitHub Projects-пен алмастыру командамен және оқытушымен келісіледі; бұл бет Jira тақтасы жасалды деп есептемейді.

| C1 | Қызметтер тізімі беті (US-03) |

Код жұмысына арналған бұтақ атауы: `feature/#N-қысқа-атау`, `bug/#N-қысқа-атау` немесе `chore/#N-қысқа-атау`. Есеп тапсырмасына feature-бұтақ талап етілмейді: оның чек-листі мен тиісті құжаттың тексерілуі қолданылады.

WIP толса, жаңа жұмысты бастамай, басталған карточкаларды аяқтауға көмектесу керек. Блокердің себебі мен оны шешетін адам карточкада жазылады. Кезең өткізілсе, шынайы оқиға журналда белгіленеді; өткен күндер ойдан жазылмайды.

«Шұғыл» — жеке баған емес, карточкадағы қызмет көрсету класы. Ерекше жағдайдың себебі мен PM келісімі жазылады; қатарынан екі шұғыл карточкаға рұқсат берілмейді.

## 5. Дайындық анықтамасы (DoR)

1. Пайдаланушы рөлі мен құндылығы жазылған.
2. Қабылдау критерийлері, соның ішінде теріс сценарийлер бар.
3. Қолданылатын функционалдық емес талаптар ескерілген: жауап уақыты, деректерді қорғау, мобильді көрініс.
4. Сыртқы тәуелділіктер анықталған және расталған: PostgreSQL схемасы Еділ Шыңтаспен келісілген; қажет болса SMS-шлюз кілті (D2) мен Telegram токені (D3) дайын.
5. Карточка бір спринтке сыяды; сыймаса, бөлінеді.
6. Интерфейс жұмысына макет бар және оны Ізбасхан Әселхан бекіткен; интерфейссіз карточкада бұл шарттың қолданылмайтыны белгіленеді.

## 6. Аяқталғандық анықтамасы (DoD)

1. Код `main` тармағына конфликтісіз біріктірілген.
2. Бірлік және интеграциялық тесттер өткен; жаңа логикаға тиісті тесттер қосылған.
3. Кодты басқа команда мүшесі қарап, approve берген.
4. QA стендте қабылдау критерийлерін және теріс сценарийлерді тексерген.
5. Қолданылатын қауіпсіздік пен өнімділік талаптары тексерілген: дербес деректер AES-256 арқылы шифрланған, логтарда телефон нөмірі жоқ, API жауабының p95 мәні 800 мс-тан төмен.
6. README немесе `docs/wiki/` құжаттамасы жаңартылған.
7. CI/CD арқылы стендке жайылған; қажет жерде Grafana көрсеткіші тексерілген.

Есептің 1.5-бөліміндегі **R-07 және R-20** кодтары 7-зертхананың тәуекелдер тізілімімен салыстырылуы тиіс ([№17](https://github.com/akaashia/dentlux-portal/issues/17)). Кодтар осы бетте расталған деп қабылданбайды. Тексеру аяқталғанша қауіпсіздік талаптары мазмұны бойынша сақталады, ал кодтар бастапқы реестрге сүйеніп түзетіледі.

| Есепті аяқтау | 13.11.2026-дан кейін | Қорытынды, 3.2-бөлім және тапсыру алдындағы тексеру |

Күн сайын күн соңында әр бағандағы карточкалардың нақты саны 2.3-кестеге енгізіледі. `cards_template.csv` көшірмесі `cards.csv` деп сақталады. Бағандары:

```text
card_id,title,created,started,review,testing,done
```

Күндер `YYYY-MM-DD` пішімінде трекердің нақты журналынан алынады. Болмаған оқиға бос қалады. `created` — карточканың құрылған күні, `started` — әзірлеуге алынған күні, `review` — ревью кезегіне түскен күні, `testing` — тестілеуге алынған күні, `done` — аяқталған күні. Скриптте Бэклог пен Ready бір жолаққа біріктіріледі; олардың жеке күнделікті саны 2.3-кестеде сақталады. Барлық қажетті тарих қамтылып, екі спринттің CSV көшірмелері бөлек архивтеледі.

## 8. Метрикаларды есептеу

Python және `pandas`, `numpy`, `matplotlib` қажет. Репозиторийдің түбірінен:

```bash
python -m pip install pandas numpy matplotlib
cd docs/lab9
# cards_template.csv көшірмесін cards.csv деп сақтап, нақты күндермен толтырыңыз.
python metrics.py cards.csv 2026-11-02 2026-11-06 sprint1
python metrics.py cards.csv 2026-11-09 2026-11-13 sprint2
```

Нәтижелер: throughput, орташа cycle time, p85 cycle time, ашық карточкалардың жасы, максималды WIP, бағандардың орташа WIP мәндері және `cfd_sprint1.png` / `cfd_sprint2.png`. Сандар есептің 2.5, 2.8 және 3.1-кестелеріне, графиктер 2.6 және 2.8-бөлімдеріне енгізіледі. Шағын үлгіде p85 тұрақсыз болатыны көрсетіледі. Бос CSV-ден шыққан нөлдер спринттің нақты нәтижесі ретінде қолданылмайды.
