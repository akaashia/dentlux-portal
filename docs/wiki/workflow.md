| Баған | Түрі | 1-спринт шектеуі | 2-спринт жоспары | Бағанға кіру шарты |

| Ревьюді күтеміз | Күту | 2 | 2 | PR ашылған, жергілікті тексерулер өткен, CI жасыл |
| Тестілеуде | Жұмыс | 2 | 2 | Басқа команда мүшесінің approve-ы бар; қабылдау критерийлері стендте тексеріледі |
| Дайын (Done) | Аяқталды | Шектеусіз | Шектеусіз | DoD толық орындалған |

29.10.2026 күні GitHub тақтасының екі көрінісінде де 20 / 5 / 4 / 2 / 2 шектеулері қойылды. GitHub баған лимиті артық карточканы қабылдауға техникалық тыйым салмайды; шектеуді команда сақтайды. Күту бағандары бөлек көрсетіледі. Ревью кезегі күн сайын дейлиде қаралады, әр PR үшін ревьюші аталады.

**2-спринттегі өзгеріс:** «Әзірлеуде» лимитін 4-тен 3-ке азайту — есептегі жоспар. Нақты әрекет 06.11.2026 ретроспективасының деректерімен бекітіледі. Бекітілген жағдайда 09.11.2026 күні екі көріністегі лимит өзгертіліп, осы беттегі өзгерістер журналы жаңартылады. Бұл өзгеріс әлі орындалды деп белгіленбейді.

## 3. Ауысу саясаттары

| Ауысу | Міндетті шарт | Жауапты |
| --- | --- | --- |
| Бэклог → Дайын (Ready) | DoR толық; теріс сценарийлер бар; карточка бір спринтке сыяды, сыймаса бөлінеді | Ізбасхан Әселхан, Жандос Арланмен келіседі |
| Дайын (Ready) → Әзірлеуде | Бір жауапты адам тағайындалған; WIP лимитінде бос орын бар; жұмыс бұтағы ашылған | Жұмысты алған әзірлеуші |
| Әзірлеуде → Ревьюді күтеміз | Қабылдау критерийлері жергілікті тексерілген; PR ашылған; CI жасыл; коммиттер `feat:`, `fix:`, `docs:` ережесіне сай | Әзірлеуші |
| Ревьюді күтеміз → Тестілеуде | Команданың басқа мүшесінің approve-ы бар; CI жасыл | Ревьюші |
| Тестілеуде → Дайын (Done) | Стендте оң және теріс сценарийлер өтті; DoD толық | Ізбасхан Әселхан немесе Жандос Арлан |

Код жұмысына арналған бұтақ атауы: `feature/#N-қысқа-атау`, `bug/#N-қысқа-атау` немесе `chore/#N-қысқа-атау`. Есеп тапсырмасына feature-бұтақ талап етілмейді: оның чек-листі мен тиісті құжаттың тексерілуі қолданылады.

WIP толса, жаңа жұмысты бастамай, басталған карточкаларды аяқтауға көмектесу керек. Блокердің себебі мен оны шешетін адам карточкада жазылады. Кезең өткізілсе, шынайы оқиға журналда белгіленеді; өткен күндер ойдан жазылмайды.

## Дайындық, аяқталу және есеп

[9-ЗЖ есебінде](../lab9.md) DoR, DoD және есептеу формулалары берілген. Карточканың ID-і, бағаны және ауысу уақыты нақты жұмыс кезінде тіркеледі. Екі кезең бойынша бастапқы CSV мен қорытынды бөлек сақталады. Ретроспективада бір өзгеріс, жауапты адам және мерзім бекітіледі.

[Тіркелген GitHub оқиғалары](../assets/lab9-github-status-events.csv) — 16 карточканың күй ауысу уақыты. №4 тарихшаларын карточкалармен салыстыру [демо чек-листінде](../demo-checklist.md) сақталған.
