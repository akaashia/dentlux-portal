# DentLux — Definition of Done (DoD)

Тапсырма **Done** деп есептелу үшін төмендегі барлық критерийлер орындалуы тиіс.

## Код сапасы
- [ ] Код `develop` (немесе `main`) ветқасына merge болды
- [ ] Code Review — кемінде 1 Approve алды
- [ ] Линтер (ESLint / Flake8) — нөл қате

## Тестілеу
- [ ] CI автотесттер өтті (GitHub Actions жасыл)
- [ ] QA (Ізбасхан Әселхан) manual тестілеу жүргізді
- [ ] Acceptance Criteria барлық пункттері белгіленді

## Құжаттама
- [ ] README / API документациясы жаңартылды (қажет болса)
- [ ] ADR жазылды (архитектуралық шешім қабылданса)
- [ ] Commit хабарламалары Conventional Commits форматында

## Жеткізу
- [ ] `staging` ортасына deploy болды
- [ ] Sprint Review-ға дайын (клиент демо ала алады)
