# ADR 002 React Node PostgreSQL

Статус: принято для реализации MVP, 22.10.2026.

Приложение отсутствовало; README допускает React и Node/Python, требует PostgreSQL и Docker. Выбран React 19 + Vite для интерфейса и Node 22 + Express 5 для REST API, поскольку единый JavaScript стек упрощает учебный запуск и тестирование. PostgreSQL используется на сервере, node:sqlite — для локального демо без инфраструктуры. Общие SQL-запросы тестируются на обеих БД. Схема миграций версионирована; защита слотов основана на блокировке врача и уникальном индексе.

Не выбран облачный backend как сервис: ТЗ требует контролируемое размещение данных в Казахстане. Публикация и проверка SLA требуют отдельной инфраструктуры клиники. SQLite не разрешён при NODE_ENV=production.

MVP взят из lab4/lab5/lab7. Более широкий список Issues не расширяет автоматически этот релиз. Отдельно сохраняются внешние зависимости: утверждённые сотрудники/прайс/контакты, SMS/Telegram credentials, согласие оператора, TLS, KZ hosting, исходный журнал для переноса, staging и PO approval.
