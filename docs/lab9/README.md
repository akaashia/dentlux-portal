# 9-ЗЖ есебі мен бастапқы деректер

- [Есеп](9-ЗЖ_DentLux_есеп.docx): бастапқы құжат сақталған, 1.6-бөлімге GitHub Projects тақтасының скриншоты мен түсіндірмесі қосылған.
- [Жұмыс процесінің ережелері](../wiki/workflow.md).
- [GitHub Wiki](https://github.com/akaashia/dentlux-portal/wiki/Жұмыс-процесі).
- [Есеп тапсырмаларының тақтасы](https://github.com/users/akaashia/projects/8/views/2): №13–18.
- [Тақта суреті](images/board-2026-10-29.jpg), 29.10.2026.
- [cards_template.csv](cards_template.csv): C1–C6 әзірлеу карточкалары; ауысу күндері бос.
- [metrics.py](metrics.py): пайдаланушы берген есептеу скрипті, логикасы өзгертілмеген.

Python ортасына `pandas`, `numpy` және `matplotlib` орнатылады. Осы папкада үлгінің көшірмесін `cards.csv` деп сақтап, трекер тарихындағы нақты күндермен толтырыңыз:

```bash
python -m pip install pandas numpy matplotlib
python metrics.py cards.csv 2026-11-02 2026-11-06 sprint1
python metrics.py cards.csv 2026-11-09 2026-11-13 sprint2
```

Командаларды әр спринт аяқталғаннан кейін оның сақталған деректерімен орындаңыз. Екі CSV көшірмесін және консоль нәтижелерін бөлек архивтеңіз. Графиктер осы жұмыс папкасында `cfd_sprint1.png` және `cfd_sprint2.png` атауларымен жасалады. Бос үлгі нақты метрикалардың орнына қолданылмайды.

№13–18 есеп тапсырмалары CSV-дегі C1–C6 әзірлеу карточкаларын алмастырмайды. Болашақ спринттердің метрикалары, R-07/R-20 кодтарының расталуы және финалдық қорытынды бұл өзгерісте толтырылмаған.
