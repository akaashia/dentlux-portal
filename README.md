# DentLux Portal

**DentLux Portal** — стоматологиялық клиникаға арналған веб-портал және онлайн жазылу жүйесі. Пациент дәрігерді, қызметті және бос уақытты таңдап, сайт арқылы қабылдауға жаза алады. Жүйе қайталама брондауға жол бермейді және растау мен еске салу хабарламаларын жібереді.

## Жобаның мақсаты

Жобаның негізгі мақсаты — клиниканың қабылдауды ұйымдастыру процесін цифрландыру және тіркеу бөлімінің жүктемесін азайту. Пациент тәулік бойы бос уақытты көріп, өзіне ыңғайлысын таңдай алады. Клиника қызметкері кестені бір жерден басқарады, ал жүйе бір слотқа екі пациенттің жазылып қалуын болдырмайды.

## Негізгі мүмкіндіктер

- **Онлайн жазылу** — қызмет → дәрігер → күн мен бос слот → деректер → растау.
- **Дәрігерлер мен қызметтер беті** — дәрігерлер, қызметтер және бағалар туралы ақпарат.
- **Телефонды растау** — SMS арқылы бір реттік код (OTP).
- **Қайталама брондаудан қорғау** — бір слотқа бір мезгілде екі пациент жазыла алмайды.
- **Әкімші панелі** — күнделікті кесте, пациент статусы («Келді», «No-show») және жазылуды жылжыту.
- **Рөлдер** — бес рөл: пациент, дәрігер, әкімші, заңгер және техникалық админ.
- **Қазақ және орыс тілдері** — интерфейстің екі тілі.
- **Деректерді қорғау** — дербес деректер AES-256 арқылы шифрланады, барлық әрекет аудит журналында тіркеледі.
- **Хабарлама модулі** — растау хабарламасы және қабылдаудан 2 сағат бұрынғы еске салу (SMS немесе Telegram арқылы).
- **Мониторинг** — Prometheus және Grafana арқылы жүйенің жұмысы мен жүктемесін бақылау.

## Жұмыс істейтін MVP және оның шекарасы

Репозиторийде клиника сайты, онлайн жазылу, қазақ/орыс интерфейсі, телефонды растау, регистратор панелі, кесте, бес рөл, деректерді шифрлау, аудит және хабарлама кезегі жұмыс істейді.

Келесі релизге қалдырылған (MVP-дан тыс): медициналық кабинет, онлайн төлем, рентген суретін жүктеу. Бұл шешім ТЗ бойынша бекітілген және [ADR-002](docs/adr/ADR-002-application-stack.md) мен [implementation.md](docs/implementation.md) құжаттарында жазылған.

## Жылдам бастау (жергілікті демо)

Талаптар: **Node.js 22.13 немесе жоғары**.

```sh
npm install
npm run dev
```

Браузерде **http://127.0.0.1:5173** ашыңыз.

Жергілікті демода PostgreSQL мен SMS кілттері қажет емес: деректер SQLite-та сақталады, ал бір реттік код форманың өзінде көрсетіледі. Қызметкерлер панеліне кіру үшін «Қызметкерлерге» бөлімінен демо-рөлін таңдаңыз.

Демо-деректер толығымен ойдан шығарылған. Нақты пациент деректерін енгізбеңіз.

## Шектеулер және келесі қадамдар

Жүйенің толық нұсқасын іске қосу үшін клиниканың нақты деректері қажет: дәрігерлердің жұмыс кестесі, қызметтер мен прайс-лист, фото мен логотип. Сонымен қатар SMS-шлюздің және Telegram-бот токенінің клиника атынан бекітілуі керек. Қазақстандағы дата-орталыққа хостинг (D4) және Docker-конфигурацияны сервердің нақты ортасына баптау келесі кезең болып табылады. Docker Compose конфигурациясы сервер үшін дайындалған; жергілікті демо npm арқылы жұмыс істейді.

- дербес деректерді шифрлау, аудит журналдары және ескі журналдардан деректерді көшіру.

## Әзірлеу моделі

Жобада **гибридті модель** қолданылады: тұрақты талаптары бар бөліктерде Predictive, ал өзгеруге бейім бөліктерде Adaptive тәсілі.

- **Predictive** — деректер қорының архитектурасы, қауіпсіздік, серверлік инфрақұрылым және негізгі жүйелік талаптар алдын ала жоспарланады.
- **Adaptive (Scrum)** — веб-сайт интерфейсі мен хабарлама функциялары қысқа, бір апталық спринттерде жетілдіріледі. Telegram/SMS арнасы сайттың қосымша арнасы ретінде қосылады.

Толық негіздеме — [ADR-001](docs/adr/ADR-001-delivery-model.md).

## Технологиялық стек

- **Frontend:** HTML5, CSS3, JavaScript, React
- **Backend:** Node.js, REST API
- **Дерекқор:** PostgreSQL (өндірісте), SQLite (жергілікті демо)
- **DevOps:** Docker Compose, Nginx, CI/CD
- **Мониторинг және қауіпсіздік:** Prometheus, Grafana, SSL/TLS, AES-256
